    What Grover actually buys you

    The pop-science version says a quantum computer tries every answer at once. If that were true, this would take one step. It doesn't. It takes about π/4 · √N rounds: a square-root speedup. Not O(1), not exponential. Quadratic.

    From these cards to real RSA

    Every card is a semiprime made of two different primes, the same shape as an RSA key: multiplying is easy, undoing it is hard. Squares like 9 = 3 × 3 work here too, but RSA always uses two different primes, so the hand sticks to those.

    Scale check. The biggest card is 35, a 6-bit number, run on 8 qubits. A real RSA key is 2048 bits, about 617 digits long.

    Grover isn't actually how you'd go after RSA. Even with the square-root speedup, a 2048-bit key would still need on the order of 2512 rounds. The real threat is Shor's algorithm, which factors exponentially faster. Estimates for breaking RSA-2048 with it have dropped from about 20 million noisy qubits (Gidney and Ekerå, 2019) to under a million (Gidney, 2025). The hardware isn't there yet, but the target keeps moving closer, which is why post-quantum cryptography is already rolling out.

    What's actually real on this page

    Every bar is a number Cirq computed. tools/export_demo.py builds the real circuit, steps through it moment by moment, and saves each state vector. This page only draws them.

    The oracle checks the rule a × b == target. The factors are never written down anywhere.

    One honest caveat: to build that oracle, the simulator asks the rule about every label, which is brute force. A real oracle would be a multiplier built out of gates that never enumerates anything. That's the one I'm building next.
